# AgenticLab

Supervision visuelle des sessions Claude Code sous Windows : un studio isométrique où chaque session active a son bureau et son personnage, avec métriques système et état réel des agents.

- Un exécutable, une fenêtre, réduction dans la zone de notification.
- Données locales uniquement, aucune télémétrie, aucune donnée inventée.
- Tauri 2 · Rust · React · PixiJS.

Documentation : [`Docs/`](Docs/) — [architecture](Docs/ARCHITECTURE.md), [sources de données](Docs/DATA_SOURCES.md), [compilation et limitations](Docs/BUILD.md).
